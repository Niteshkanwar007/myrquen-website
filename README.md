# MYRQUEN Website

Official marketing website for MYRQUEN, contextual intelligence for commercial decisions.

## Stack

- React 18
- TypeScript
- Vite
- Lucide React

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Current implementation notes

The initial site is a responsive marketing front end with:
- Product positioning for freelancers and agencies
- Product workflow and FAQ sections
- Enquiry / demonstration modal
- Custom CSS-generated glass-inspired hero artwork
- Basic SEO metadata and favicon

The enquiry form is currently presentation-only. It does not transmit or store personal information. Connect it to an approved email, CRM or form endpoint before launch.

Product pricing, licence terms, current compatibility matrix, verified performance data, contact details and final product screenshots are intentionally not invented. Add confirmed information before publishing commercial claims.

## Deployment

Designed for deployment on Vercel or any static hosting provider.
